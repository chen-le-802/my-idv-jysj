# 分层地图分类图库：前端技术实现记录

## 方案

使用 Vue 3 + Vite 构建单页静态网站。地图元数据与图片路径由 `src/data/maps.ts` 管理；图片位于 `public/maps/`，构建时原样复制到 `dist`，因此不需要接口、数据库或服务端渲染。

```text
App
├─ 分类导航与地图分组
├─ MapCard（封面卡片）
└─ MapViewer（全屏查看器）
   ├─ 当前地图与前后切换
   └─ B1/B2/B3 图层切换
```

## 状态与数据流

- `activeCategoryId`：当前分类；由它计算列表和同分类的查看器导航范围。
- `selectedMapId`：当前打开的地图；为空时关闭查看器。
- `activeLayerId`：仅在 `MapViewer` 内维护；切换地图后恢复为该地图的第一层（当前为 B1）。
- `maps.ts`：每条地图的名称、分类、封面、图层列表。某地图缺少图层时不配置对应项，界面自动隐藏。

## 适配与性能

- 桌面端为四列卡片网格，移动端为两列。
- 移动端查看器保留地图原始可读宽度并允许容器横向滚动；分类与图层标签可横向滚动。
- 封面图启用浏览器原生懒加载；正式图片建议使用 WebP 或 AVIF，并在不影响文字可读性的前提下压缩。

## 部署

执行 `npm run build` 生成 `dist`。EdgeOne Pages 配置构建命令为 `npm run build`、输出目录为 `dist`。
