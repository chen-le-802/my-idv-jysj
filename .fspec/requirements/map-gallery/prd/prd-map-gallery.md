# 分层地图分类图库 PRD（实现基线）

> 创建日期：2026-11-11
> 来源：用户沟通、人工提供截图
> 状态：已按“先交付可替换演示骨架”启动实现

## 1. 目标与范围

这是一个无需后端的静态地图检索站。访客按分类浏览地图卡片，打开卡片后查看地图全览和可用楼层。正式的分类、地图元数据和图片由用户后续提供。

本阶段包含：

- 分类筛选与“全部”视图；
- 地图封面卡片和数量显示；
- 全屏地图查看器；
- 全览/楼层切换；
- 当前分类中前后切换地图；
- 手机、平板和桌面端适配；
- 本地演示数据及图片替换说明。

不包含：登录、后台管理、数据库、用户上传、收藏、评论、下载、统计。

## 2. 交互规则

1. 默认选择“全部”，地图按分类分组展示。
2. 选择具体分类后，仅显示该分类地图卡片。
3. 点击卡片打开深色全屏查看器；Esc、关闭按钮或点击遮罩可退出。
4. 查看器默认显示“全览”；地图存在楼层图时显示相应楼层标签。
5. 前后控制仅在当前筛选结果内循环切换地图；切换时回到该地图的全览。
6. 移动端的分类和图层标签可横向滚动；地图支持浏览器原生缩放基础上，后续可扩展手势缩放。

## 3. 设计与交互分析摘要

设计来源：人工提供截图，无精确 Figma 规格。

- 列表页：浅色背景、顶部分类切换区、响应式卡片网格。
- 分类选中态：暖金色填充；未选中态：浅色中性背景。
- 地图查看器：黑色/深色背景，顶部显示名称、序号、图层导航和关闭按钮；大图居中显示。
- 空态：无匹配地图时显示简短提示。

## 4. 验收基线

- 项目可通过 `npm run build` 生成 `dist`。
- 演示分类可筛选；点击卡片可打开、关闭、切换地图和图层。
- 375px 宽度下不发生横向页面溢出，卡片、分类和查看器可操作。
- 用户替换数据文件与静态资源后，无需修改页面交互逻辑。

## 5. 待确认项
